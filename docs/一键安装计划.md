# Mac 一键安装脚本计划

## 目标与边界

1. 安装端仅使用 macOS 自带 Bash、curl、ditto、plutil、xmllint 和 xsltproc，不依赖 Git、Node.js、npm、Python、编译器或开发工具。
2. 从 GitHub main 下载源码压缩包，只复制 6 个已可运行的静态文件，不执行构建或下载第三方运行库。
3. 本地完整源码目录运行 install.sh 时直接使用本地文件，可不联网。
4. 默认安装到用户 WPS Mac 的 jsaddons 目录，备份原配置和同版本旧文件；只替换本项目的 online/offline 记录，保留其他加载项。
5. 配置格式有误时拒绝覆盖；安装失败回退尚未提交的文件替换。WPS 正在运行时提示保存并退出，不强制关闭。
6. 当前只制作 Mac 安装器，不扩展 Windows、自动卸载或后台更新。

## 实施与验收

1. 新建 tests/install-macos.test.cjs，先确认安装脚本缺失导致验证失败。
2. 新建 install.sh，覆盖首次安装、重复安装合并备份和损坏配置不变三类主要风险。
3. 验证时使用 WPS_JSON_GET_ADDONS_DIR 指向临时目录，PATH 设为不含工具的目录，证明脚本不依赖开发环境。
4. 再将单独的脚本复制到临时目录，验证真实 GitHub 下载路径；不操作实际 WPS 配置。
5. 更新 README，记录远程一键命令、本地安装方式、备份位置及兼容性限制。
6. 完成独立审查与 shell 语法检查后交付。真实 Mac WPS 的单元格计算仍需启用后验证。

## 验证结果

1. 安装脚本缺失时，3 项自行编写的安装验证均失败；实现后均通过。
2. 修正了 plutil 的校验调用：JSON 转换可以解析函数声明，lint 模式不能直接校验该 JSON。
3. 本次自行编写的 8 项函数验证和 3 项安装验证全部通过，bash 语法检查和差异空白检查通过。
4. 已把单独的 install.sh 复制到临时目录，在 PATH 不含任何工具的条件下从真实 GitHub main 下载压缩包并安装；6 个文件与本地一致，未触碰实际 WPS 配置。
5. 独立只读审查未发现需要修复的确定缺陷。
6. 不承诺并发安装、断电或强制结束进程的事务恢复；实际 WPS 客户端加载和公式计算仍需用户启用后验证。
