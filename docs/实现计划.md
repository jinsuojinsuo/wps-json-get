# WPS JSON 字段提取加载项实现计划

## 目标和约束

1. 在指定目录制作本地 WPS 表格加载项，提供 `=JSON.GET(A2,"user.name")`。
2. 支持点分字段、从 0 开始的数组下标、双引号括号字段名；不实现完整 JSONPath。
3. 返回数值、文本和布尔值；对象和数组返回 JSON 文本，null 返回空文本。
4. 格式错误、路径错误、字段缺失返回以 `#JSON!` 开头的说明文本；该文本不是电子表格原生错误值。
5. 拒绝超出 JavaScript 安全整数范围的 JSON 数值；合法的 16 位整数作为文本返回，避免表格丢失精度。长编号推荐在 JSON 中使用字符串。
6. 只创建本目录内的代码、配置、构建结果和中文说明，不创建 Git worktree，不修改 WPS 配置。
7. 不执行用户编写的测试，仅运行本次自行编写的验证。

## 架构和文件

1. `js/functions.js`：JSON 解析、路径取值、公式错误文本和函数元数据，兼容浏览器与 Node.js。
2. `main.js`、`index.html`、`ribbon.xml`：WPS 入口、函数注册和状态按钮。
3. `manifest.xml`、`functions.json`：官方加载项与自定义函数声明。
4. `scripts/build.cjs`：仅复制运行资源到 dist，验证函数元数据一致。
5. `package.json`：官方 wpsjs 工具和构建、调试、验证入口。
6. `tests/json-get.test.cjs`：针对解析、精度、宿主注册风险的少量独立用例。
7. `README.md`：安装调试、公式示例、错误和兼容性说明。
